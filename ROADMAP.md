# Roadmap

| Version | Focus | Exit criterion |
| --- | --- | --- |
| v0.1 Foundation | Contracts, Task System, events, stub model | Verified state transitions and observable stub execution |
| v0.2 Core Runtime | Execution lifecycle, context, runtime, stub strategy | Traceable persisted execution through ports |
| v0.3 Models + Tools | Provider-independent model stub and safe tool gateway | Explicit, correlated model and tool capabilities |
| v0.4 Orchestration | Declared sequential model/tool operations | Correlated stop-on-failure orchestration |
| v0.5 Memory + Context | Immutable execution context and scoped memory gateway | Explicit, correlated in-memory memory operations |
| v0.6 Observability + Governance | Correlated audit/metrics and enforced operation policy | Governed, inspectable execution |
| v0.7 Platform API/UI | Platform API and web product boundary | Web Platform consumes stable API contracts |
| v0.8 Multi-Agent | Agent coordination and delegation | Governed multi-agent execution |
| v0.9 Autonomous Operations | Bounded autonomous operations | Explicit operational limits and auditability |
| v1.0 AI Operating Platform | Integrated engine, platform and applications | Governed enterprise AI platform |
