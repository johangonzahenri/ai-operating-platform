# Roadmap

| Version | Focus | Exit criterion |
| --- | --- | --- |
| v0.1 Foundation | Contracts, Task System, events, stub model | Verified state transitions and observable stub execution |
| v0.2 Single-Agent Execution | One real model and one real tool adapter | End-to-end agent execution through ports |
| v0.3 Observability & Policy | Tracing, metrics, first authorization rules | Auditable policy decisions |
| v0.4 Multi-Tool & Memory | Persistent memory and expanded tools | Replaceable storage adapters |
| v0.5 Orchestration | Workflows, retries, branches | Deterministic workflow execution |
| v1.0 Multi-Agent Platform | Delegation, providers, human approvals | Governed multi-agent operations |
