## 7. Architectural Invariants
1. **Single Runtime (`CoreRuntime`):** All execution paths (tasks, orchestration, agents) pass strictly through `CoreRuntime.execute()`. No parallel or bypass runtimes exist.
2. **State Machine Integrity:** Finite state machines for `Task` (`SUBMITTED → QUEUED → RUNNING → COMPLETED | FAILED | CANCELLED`) and `Execution` (`QUEUED → RUNNING → COMPLETED | FAILED | CANCELLED`) reject terminal transitions.
3. **Agent Boundary:** Agent is a domain entity and execution strategy, not a runtime daemon.
4. **Governance Fail-Closed:** Policy evaluation failures or violations strictly abort execution (`FAIL CLOSED`).
5. **Memory Partitioning:** Default isolation scope is `agent-${id}`, preventing cross-agent data contamination.
6. **Correlation & Observability:** All events strictly retain `traceId`, `taskId`, `executionId`, and `agentId`.
