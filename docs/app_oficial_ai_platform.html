for (let iteration = 0; iteration < maxIterations; iteration++) {
  if (token.isCancelled) return this.handleCancellation(operation);
  const step = plan.steps[iteration];
  const observation = await this.executeStep(step, operation);
  const decision = await this.evaluator.evaluate({ step, observation });
  if (decision.type === 'COMPLETE') break;

Blueprint 3: Arquitectura de Agentes de Primera Clase

Microchip de capacidades, lista blanca de herramientas y el invariante "Agent ≠ Execution"

Toca para ampliar y explorar las capacidades del agente
Tool Whitelisting

El agente no tiene acceso indiscriminado al sistema. Solo puede invocar herramientas explícitamente autorizadas en su array inmutable agent.tools.

Memoria Aislada

Cada agente posee un espacio de memoria particionado (agent.memoryScope). No existe fuga de contexto entre agentes de distintas aplicaciones.

"Agent ≠ Execution"

Un agente es solo una configuración declarativa de capacidad. Toda corrida real es una tarea registrada y gobernada por el único CoreRuntime.

Ciberseguridad Estricta
Intercepción Fail-Closed (Seguridad por Defecto)

Si la pasarela de políticas evalúa DENY o experimenta una excepción no controlada, la ejecución se interrumpe de inmediato. No existe paso por omisión permisiva (fail-open).

Observabilidad y Auditoría
Tripleta Inmutable { traceId, taskId, executionId }

Cada hecho emitido al almacén de eventos lleva estampada la correlación unívoca de auditoría. Los snapshots son sellados permanentemente con inmutabilidad estricta.
